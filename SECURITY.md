# Security policy

FairyWriter is pre-release software and does not yet promise security support
windows for published versions.

Please do not open a public issue for a vulnerability that could expose user
documents, execute code, or bypass filesystem boundaries. Report it privately
through [GitHub Security
Advisories](https://github.com/navjack/FairyWriter/security/advisories/new)
with affected versions, reproduction steps, and impact.

Ordinary crashes, rendering defects, and non-sensitive bugs belong in the
public issue tracker.
