# FairyWriter Agent Working Memory

Before changing this repository, read these files in order:

1. `SCRATCH.MD`
2. `plan.md`
3. `DEVELOPMENT_STATUS.md`
4. `docs/HANDOFF_2026-07-26.md`
5. `docs/SNES_FRONTEND.md`

`SCRATCH.MD` is the project's durable external working brain. It exists to
survive context compaction and agent handoffs. It is not generated output and
must never be deleted or ignored during cleanup.

After meaningful implementation, diagnosis, validation, packaging, cleanup, or
scope decisions, update the current sections in `SCRATCH.MD` before ending the
task. Keep these items accurate:

- active branch and dirty working-tree boundaries;
- current product and ownership invariants;
- discoveries, root causes, rejected approaches, and performance constraints;
- completed work and artifact freshness;
- automated validation evidence and remaining manual acceptance;
- the next concrete action.

Preserve useful superseded material under the archive section instead of
letting stale history obscure the current resume point or deleting it.
